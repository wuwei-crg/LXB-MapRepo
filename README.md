# LXB-MapRepo

Canonical map repository for LXB ecosystem.

## Policy
- Do not edit `manifests/**` manually.
- Do not maintain `index.json` manually.
- Submit map artifacts only (`nav_map.json.gz` + `meta.json`).
- CI regenerates manifest files after merge to `main`.

## Repo Layout
- `stable/maps/<package>/<map_id>/...`
- `candidates/maps/<package>/<map_id>/...`
- `manifests/<lane>/latest.json` (generated by CI)
- `manifests/all/latest.json` (generated by CI)

## Local Rebuild
```bash
python tools/build_manifest.py --repo-root .
```
